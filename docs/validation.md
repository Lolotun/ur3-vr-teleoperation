# Проверка переноса

Перенос не означает повторную проверку на физическом UR3.
Движение робота и команды захвату при подготовке репозитория не отправляются.

Выполнено: проверка Python/Bash синтаксиса, Compose config, зависимостей Unity
в manifest/lock и хешей перенесённых исходников. Полная новая Docker-сборка
и запуск на физическом роботе пока не подтверждены.

2026-10-26, первый импорт Unity:

- В Editor.log найдена ошибка CS0103 Meta XR Core 85.0.0 на Linux
  (`downloadedInstallerPath`). Применён scripts/patch-meta-xr.py; после этого
  Editor выполнил компиляцию и ReloadAssembly без новых ошибок CS в проверенном
  участке лога. Повторный запуск исправления корректно сообщает Already patched.
- В пакетах ETH B2W, Gr2, Psyonic, Tytan и Spot есть `.meta` без соответствующих
  файлов. Git LFS установлен; причина отсутствия ресурсов в пакетах ещё не установлена.
  У перенесённых Assets/TutorialAssets таких пропусков не обнаружено.
- WorkshopScene через меню/базу роботов имеет ссылки на другие модели ETH;
  удалять их зависимости без изменения этих ссылок нельзя. Импорт не доказывает
  работоспособность всех моделей. Предупреждения о ресурсах пока не устранены.
- Meta XR Project Setup Tool сообщает о настройках XR. Нужна отдельная проверка
  списка Required fixes для активной целевой платформы; все настройки автоматически
  не менялись.

Для завершения проверки на установке нужны:

1. Открытие чистого Unity-проекта, восстановление пакетов и компиляция.
2. Сборка нового Docker-образа и запуск backend.
3. Подключение Unity/Quest, наличие raw/safe Twist и /joint_states.
4. Проверка движения XYZ и захвата на роботе в условиях прежней установки.

## Виртуальный режим — 2026-10-26

- В контейнере `ur3-vr-workshop:humble` с `--network none` перенесённый
  teleop_core собран заново через colcon в отдельном временном workspace.
- Из нового workspace запущен servo_sim.launch.py без ROBOT_IP,
  с отдельным ROS_DOMAIN_ID=211 и портом Endpoint 11000.
- Проверена цепочка тестового Twist: вход → safe Twist → траектория MoveIt Servo
  → изменение шести конечных положений суставов в /joint_states.
- В графе ROS не было ur_speedl_wifi_bridge, robotiq_gripper_bridge,
  controller_manager. После проверки процессы и временный контейнер остановлены.
- Проверены выбор servo_sim командами servo/sim и сохранение проверки ROBOT_IP
  для real up, синтаксис Bash/Python/XML и итоговая команда Compose.

Эта проверка использует зависимости существующего workshop-образа. Она не
подтверждает свежую загрузку apt/Git-зависимостей Dockerfile или интерактивное
управление в Unity/Quest. Перед проверкой новой сборки выполнить run.sh build.

Вращение включено только в виртуальном режиме; настройки реального speedl
не изменены. Позиционное слежение не добавлено.

## Ветка ur_rtde

- 12 тестов pose_control: anchors, rearm, rotation/frame mapping, ограниченный
  servo шаг, preview без Control, остановка при отклонении команды.
- 2 интеграционных ROS-теста с поддельными RTDE в контейнере без сети: preview
  не создаёт Control, команды достигают mock, stale input и frozen RTDE feedback
  останавливают управление, удержание Trigger не возобновляет движение после fault.
- Новые узлы собраны colcon; rtde_real.launch.py --show-args проходит.
- Wheel ur_rtde 1.6.2 для Python 3.10 загружен и импортирован офлайн в контейнере;
  проверены сигнатуры servoL, isPoseWithinSafetyLimits, getTimestamp без соединения.
- Синтаксис Bash/Python и RTDE Compose проверены. Ссылки/уникальность IDs нового
  Unity-компонента проверены; Pose Mode в сцене оставлен выключенным.
- Свежая полная Docker-сборка, компиляция/ввод Unity и поведение реального UR3
  после этих изменений не подтверждены. Физические команды не отправлялись.
